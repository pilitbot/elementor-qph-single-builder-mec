Widget-based single event builder for Modern Events Calendar (MEC) using Elementor.

== Description ==
This plugin adds a dedicated Elementor widget category for MEC Single Event templates and registers ESB widgets for event data blocks (title, date, location, booking, map, countdown, etc.).

== Installation ==
1. Upload folder `elementor-qph-single-builder-mec` to `/wp-content/plugins/`.
2. Activate plugin from WordPress admin.
3. Ensure Elementor and Modern Events Calendar are active.
4. Edit your MEC single template with Elementor and use "QPH MEC Single Builder" widgets.
